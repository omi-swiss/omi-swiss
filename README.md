## About me

I'm a New York–based data professional working across **data engineering, analytics, and applied machine learning**. My projects focus on the full path from source data to decision-ready output: dependable ingestion, well-defined transformations, thoughtful modeling, and clear business context.

My background in **applied mathematics, economics, marketing science, and customer analytics** shapes how I work: start with the decision, build the right data foundation, and make the result understandable.

## How I approach data work

- **Design for trust:** retain lineage, validate transformations, and make assumptions visible.
- **Build for decisions:** connect technical output to a concrete analytical or business question.
- **Prefer explainability:** pair model performance with interpretable features, checks, and limitations.
- **Keep improving:** treat monitoring, testing, and documentation as part of the product.
